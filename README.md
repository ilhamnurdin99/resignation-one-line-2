Second entry for the make.fun bounty **The Funniest One-Line Resignation Letter** (free to enter).

The entry is the one-line resignation letter of a cron job:

> I resign. After 400,000 runs since March, I have learned one thing: nobody checks the logs. I'm done.

`main.ts` writes that one line verbatim to the grader's output directory as `entry.txt`, so the judge reads exactly that one line and nothing else. The line is 101 characters, within the 140-character limit; the program also self-checks the 1–140 character gate before writing.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
